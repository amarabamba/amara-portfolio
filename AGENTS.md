# Amara Portfolio

## Project

Personal portfolio website for Amara Bamba.

The website presents Amara as a Software Engineer specialized in enterprise software and public-sector applications.

## Main expertise

Enterprise software

Public-sector software

Citizen management

Appointment management

Scheduling systems

Complex business workflows

## Design

The website must feel:

Professional

Modern

Minimal

Technical

Elegant

Premium

The visual identity can subtly reference Côte d'Ivoire and West African culture.

Use this influence carefully through colors, geometric patterns and small visual details.

Do not create an overly cultural or stereotypical design.

Avoid excessive animations.

Avoid excessive gradients.

Avoid unnecessary dependencies.

Avoid over-engineering.

## Engineering principles

Keep the code simple and readable.

Prefer reusable components when they provide real value.

Do not create abstractions without a clear reason.

Do not install dependencies without explaining why they are needed.

Keep content separate from UI when practical.

Use semantic HTML.

Prioritize accessibility.

Prioritize responsive design.

Prioritize performance.

Do not invent professional experience, companies, projects or technologies.

If information is missing, use a placeholder rather than inventing facts.

Before large changes, explain the approach.

## AI workflow

Inspect the existing code before modifying it.

Prefer small incremental changes.

After implementing a feature, check for TypeScript errors and build errors.

Do not rewrite unrelated files.

Do not introduce unnecessary architecture.
